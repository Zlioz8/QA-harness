# P7 · El manual describe el entorno del autor (Apache/PHP8.2), no el destino (nginx/PHP8.1); §5 no compila

> Severidad de la auditoría: **Media**. Defecto de documentación con impacto de seguridad.

## Dónde vive

`docs/Manual despliegue CENTRO COMPLETO.md` (rama `lmsActividad`, commit 22/08): §2.4 (Apache), §1
(PHP 8.2), §5.1–§5.8 (parches al core).

## Por qué es tangible

- **Servidor web:** el manual manda Apache (`Alias`, `mod_rewrite`, `mod_proxy`); el destino real
  (`zajunavideo5.com`) es **nginx/1.24.0** (`Server: nginx`, verificado). Es el mismo eje que en #7.
- **PHP:** exige 8.2; el core corre **8.1.34** (verificado). Las apps funcionan igual, pero el
  requisito no describe el destino.
- **Parches §5 rotos:** `$external_gradebook_url = new_url;` (constante `new_url` inexistente →
  *undefined constant*), `html_writer::link($new_url, $coursenamelink;)` (error de sintaxis), y el
  bloque §5.2 comentado con `/* */` (la redirección no se ejecuta). Verificado leyendo el manual.
- **Consecuencia de seguridad:** seguir el manual (Apache sin bloqueo de ocultos) reabre P5
  (.env/.git servibles); el servidor real lo evita solo por usar nginx.

## STRIDE

**No encaja limpiamente en STRIDE**: es un defecto de documentación/proceso, no una amenaza con actor
y activo. Su impacto de seguridad se canaliza vía P5 (Information Disclosure), que se modela allí. Se
declara en vez de forzar una casilla.

## CVSS

**Sin vector CVSS propio**: un defecto de documentación no es una vulnerabilidad explotable con vector
AV/AC/PR. Su severidad («Media») viene del riesgo que induce (P5) y del daño operativo de unos parches
que no compilan sobre un core compartido. Forzar un CVSS aquí sería inventar precisión.

- **A.5.37 Procedimientos operativos documentados** — el manual debe describir el destino real.

- **A.8.29 Pruebas de seguridad en desarrollo** — validar los procedimientos antes de publicarlos.

## Qué debe asimilar el equipo

Un manual de despliegue es un contrato con el operador: si describe otra máquina, este no distingue un
fallo real de una divergencia esperada. Se documenta el **destino** (nginx, la versión de PHP real,
las rutas del core), o se parametriza declarando los supuestos. Todo bloque de código del manual debe
pasar `php -l` antes de publicarse; mejor aún, la integración con la UI del core se hace por plugin
(P4), no pegando parches a mano.

## Criterio de cierre

El manual nombra el servidor web y la versión de PHP reales del destino, incluye el bloqueo de
ficheros ocultos (P5) como paso obligatorio, y los bloques del §5 copiados literalmente pasan `php -l`.
