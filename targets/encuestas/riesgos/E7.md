# E7 · Higiene de cabeceras: server_tokens y CSP sin fallback

> Severidad de la auditoría: **Baja**. Documento probatorio y formativo.

## Dónde vive

En la capa de servidor: la config de nginx que sirve zajunavideo5 (cabecera `Server`) y la CSP que
emite la API (`app/Http/Middleware/SecurityHeaders.php`).

## Por qué es tangible

- **(a) Divulgación de versión:** `curl -I https://zajunavideo5.com/api/contact-info` devuelve
  `Server: nginx/1.24.0 (Ubuntu)`. Verificado por el spec de mecanismos (Playwright) y por ZAP
  passive (regla 10036). Un atacante empareja esa versión exacta con CVEs públicos conocidos de
  nginx 1.24.0 para afinar su siguiente paso. Es reconocimiento, no explotación directa.
- **(b) CSP sin directivas de reserva:** ZAP passive marcó 9 veces `CSP: Failure to Define Directive
  with No Fallback` (regla 10055). La CSP de la API declara `default-src 'self'` pero no las
  directivas explícitas (`script-src`, `form-action`, `frame-ancestors` ya está…). En una API que
  sirve JSON el impacto es mínimo; importaría de verdad en el host de la SPA, que el README §4
  delega correctamente.

## OWASP

- **A05:2021 Security Misconfiguration**: divulgación de información del servidor y cabeceras de
  seguridad incompletas son el ejemplo de libro de la categoría.
- **WSTG-INFO-02** (Fingerprint Web Server) para (a); **WSTG-CONF-12** (Testing for Content
  Security Policy) para (b).
- **ASVS v4.0 — 14.4.x** (cabeceras de respuesta HTTP de seguridad).

## MITRE

- (a) **CWE-200: Exposure of Sensitive Information** / **CWE-497: Exposure of System Data**.
  ATT&CK **T1592.002 Gather Victim Host Information: Software** (reconocimiento).
- (b) **CWE-1021: Improper Restriction of Rendered UI Layers** (aproximado para CSP incompleta).

## STRIDE

**Information Disclosure** para (a). (b) es defensa en profundidad contra **Tampering**/XSS, no una
vulnerabilidad activa por sí misma dado que la API sirve JSON.

## CVSS

**CVSS 3.1: 3.1 (Baja)** — `AV:N/AC:H/PR:N/UI:N/S:U/C:L/I:N/A:N` para (a): fuga de información menor,
útil solo como reconocimiento. (b) es informativo, sin vector propio.

## ISO/IEC 27001

- **A.8.9 Gestión de la configuración** — configuración de servidor que revela más de lo necesario.
- **A.8.26 Requisitos de seguridad de las aplicaciones** — las cabeceras de seguridad forman parte
  de los requisitos de la aplicación web.

## Qué debe asimilar el equipo

El principio de mínima divulgación: un servidor no debe anunciar su versión exacta
(`server_tokens off;`). Y una CSP se define con TODAS sus directivas relevantes explícitas, no
confiando en que `default-src` cubra por herencia — aunque en una API el riesgo sea bajo, la
disciplina se entrena en lo pequeño para que esté cuando importe (la SPA).

## Criterio de cierre

`curl -I` no muestra versión en `Server:` (tras `server_tokens off;`). El escaneo pasivo de ZAP
deja de marcar 10036 (server leak) y 10055 (CSP sin fallback).
