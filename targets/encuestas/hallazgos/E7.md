## Qué está pasando

Higiene de cabeceras HTTP, dos puntos menores. **(a)** nginx anuncia su versión exacta en la
cabecera `Server: nginx/1.24.0 (Ubuntu)` (falta `server_tokens off`). **(b)** ZAP marcó 9 veces
`Content-Security-Policy: Failure to Define Directive with No Fallback`: la CSP de la API declara
`default-src 'self'` pero no las directivas explícitas (`script-src`, `form-action`…), que caen al
default.

## Por qué es un riesgo

Bajo. (a) facilita a un atacante emparejar la versión con CVEs conocidos — reconocimiento, no
explotación directa. (b) tiene impacto mínimo en una API que sirve JSON/imágenes (no HTML con
scripts); la CSP importa de verdad en el host de la SPA, que el README §4 ya delega correctamente.

## Recomendación de remediación

(a) `server_tokens off;` en la config de nginx. (b) completar las directivas de CSP explícitas en
`SecurityHeaders.php` si se quiere cerrar el aviso, aunque en una API es opcional.

## Verificación

`curl -I` no debe mostrar la versión en `Server:`. El escaneo pasivo de ZAP dejará de marcar 10035
(server leak) y 10055 (CSP sin fallback).
