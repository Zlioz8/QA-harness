## Qué está pasando

`composer.json` y `composer.lock` están listados en el `.gitignore` del repositorio, así que un
clon limpio no los contiene. Sin ellos `composer install` falla con *"could not find a
composer.json file"* y no hay `vendor/`.

Lo confirma el propio `DEPLOY.md` que entregó el equipo (sección 2): *«composer.json y
composer.lock NO están en el repositorio… Hay que copiarlos aparte desde una máquina que ya tenga
el proyecto funcionando»*.

Verificado al levantar el proyecto en el laboratorio: hubo que aportar un `composer.json`
reconstruido desde la documentación para que la aplicación arrancara.

## Por qué es un riesgo

Tiene dos consecuencias de naturaleza distinta y ambas importan.

**Operativa:** el proyecto no se puede desplegar desde su propio repositorio. Un servidor nuevo,
o una recuperación ante desastre, depende de que exista otra máquina funcionando de la que
copiar archivos a mano. Si esa máquina se pierde, se pierde la lista de dependencias.

**Sobre esta auditoría:** sin manifiesto no hay nada que analizar, y la dimensión de CVE de
dependencias devuelve **0 sobre un máximo de 50** — un cero que en el informe se lee igual que un
árbol de dependencias limpio. Es el resultado más engañoso que este laboratorio puede producir, y
por eso el contrato de despliegue se comprueba antes que ninguna medida. **La cifra de CVE de
esta ronda no es autoritativa.**

## Recomendación de remediación

- *Explicación:* un `composer.lock` no es un secreto: es el único registro de qué versiones
  corren realmente. Ignorarlo suele venir de confundirlo con `vendor/`, que sí debe ignorarse.
- *Orientación:* retirar ambas líneas del `.gitignore` y commitear los dos archivos tal como
  están hoy en el servidor. `vendor/` se queda ignorado.
- Una vez commiteados, esta auditoría podrá medir CVE de dependencias de verdad; hasta entonces
  esa dimensión se reporta como NO AUTORITATIVA.

## Verificación

```bash
git clone <repo> /tmp/adi-limpio && cd /tmp/adi-limpio
test -f composer.json && test -f composer.lock && composer install --no-dev
```
Debe completar sin copiar nada de otra máquina.
