## Qué está pasando

OWASP ZAP detectó listado de directorios habilitado en tres rutas del entorno de validación:

```
Directory Browsing  https://zajunavideo.com/adi/assets/
Directory Browsing  https://zajunavideo.com/adi/helpers/
Directory Browsing  https://zajunavideo.com/adi/img/
```

Apache responde con el índice generado (`Parent Directory`) en vez de un 403 o el `index.html`.

## Por qué es un riesgo

Es reconocimiento, no acceso: expone la estructura interna, los nombres de archivo y las fechas
de modificación. En `helpers/` hay JavaScript propio del proyecto, lo que permite enumerar la
lógica de cliente sin adivinar rutas.

Por sí solo es de impacto bajo; su valor está en que acorta el trabajo previo a los hallazgos
serios de esta lista.

## Recomendación de remediación

- *Explicación:* el listado de directorios está activo por configuración del servidor, no por
  algo del código.
- *Orientación:* `Options -Indexes` en la configuración de Apache, aplicado al `VirtualHost`
  entero y no directorio a directorio.

## Verificación

```bash
for d in assets helpers img; do
  curl -s -o /dev/null -w "$d %{http_code}\n" https://zajunavideo.com/adi/$d/
done   # ninguno debe dar 200 con índice
```
